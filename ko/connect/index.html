AI 앱 연결하기

ChatGPT, Claude, Codex, Cursor 등 원격 MCP를 지원하는 AI 앱을 연결할 수 있어요. AI가 계획하면 iPhone 앱이 카드를 한 장씩 보여 줘요.

앱은 현재 영어로 제공돼요.

서버 주소

https://mcp.one-by.one/mcp

Streamable HTTP, OAuth 로그인. API 키나 토큰은 필요 없어요.

연결 방법

AI 앱에 서버 주소를 추가하고, 브라우저에서 one-by.one 계정으로 로그인해 권한을 승인하세요. 앱은 3개까지 연결할 수 있어요. 연결을 끊으려면 iPhone 앱의 Settings › AI apps에서 Disconnect를 누르세요.

권한

앱이 할 수 있는 일이에요.

  • context:read — 계획에 필요한 공유 정보를 읽어요.
  • activity:read — 계획과 활동 기록을 읽어요.
  • activity:write — 계획을 만들거나 바꾸고 활동을 기록해요.

확인되지 않은 앱은 승인 화면에 Unverified app으로 표시돼요. 연결하려던 앱이 맞는지 확인하세요. AI에 공유되는 정보는 개인정보 처리방침(영어)에 있어요.

앱별 설정

기존 설정은 두고 onebyone 항목만 추가하세요. 토큰이나 클라이언트 비밀 값은 필요 없어요. 메뉴 이름은 버전마다 달라요.

ChatGPT Claude Claude Code Codex CLI Cursor VS Code Gemini CLI Windsurf

ChatGPT · Apps / Connectors

  1. 계정에서 허용하면 Developer mode를 켜세요(Settings → Security and login → Developer mode).
  2. Plugins에서 +를 눌러 이름을 one-by.one으로 정하고 https://mcp.one-by.one/mcp을 입력하세요. 이전 버전에서는 Apps 또는 Connectors로 표시돼요.
  3. 로그인을 마친 뒤 새 대화의 도구 메뉴에서 선택하세요. 요금제와 워크스페이스 정책에 따라 사용 가능 여부가 달라져요.

공식 문서

Claude · claude.ai / Desktop

  1. Customize → Connectors에서 커스텀 웹 커넥터를 추가하세요.
  2. 이름은 one-by.one, 주소는 https://mcp.one-by.one/mcp로 입력하세요.
  3. 로그인 인증을 선택하고, 클라이언트 등록 방법이 보이면 자동 등록(Register automatically)을 선택하세요. 로그인을 마친 뒤 대화에서 커넥터를 켜세요.

Claude Desktop도 같은 커넥터를 써요. Team·Enterprise에서는 관리자가 먼저 추가해야 할 수 있어요.

공식 문서

Claude Code

터미널에서 실행하세요.

claude mcp add --transport http onebyone https://mcp.one-by.one/mcp

그다음 대화에서 /mcp를 입력하고 onebyone을 선택해 브라우저에서 로그인하세요.

공식 문서

Codex CLI

터미널에서 서버를 추가하고 로그인하세요.

codex mcp add onebyone --url https://mcp.one-by.one/mcp
codex mcp login onebyone

설정 파일을 쓴다면 ~/.codex/config.toml에 아래를 추가하고 codex mcp login onebyone을 실행하세요.

[mcp_servers.onebyone]
url = "https://mcp.one-by.one/mcp"

Codex에서 /mcp로 연결 상태를 확인하세요.

공식 문서

Cursor

.cursor/mcp.json(프로젝트) 또는 ~/.cursor/mcp.json(모든 프로젝트)에 추가하세요.

{
  "mcpServers": {
    "onebyone": {
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

Cursor를 다시 열고 로그인 안내를 따르면 Agent에서 도구를 쓸 수 있어요.

공식 문서

VS Code · GitHub Copilot

.vscode/mcp.json에 추가하세요. 사용자 설정은 MCP: Open User Configuration으로 열 수 있어요.

{
  "servers": {
    "onebyone": {
      "type": "http",
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

편집기에서 onebyone의 Start를 누르고 브라우저에서 로그인한 뒤 Copilot Agent에서 도구를 켜세요.

공식 문서

Gemini CLI

~/.gemini/settings.json 또는 프로젝트의 .gemini/settings.json에 추가하세요. OAuth 정보는 자동으로 감지해요.

{
  "mcpServers": {
    "onebyone": {
      "httpUrl": "https://mcp.one-by.one/mcp"
    }
  }
}

그다음 Gemini CLI 대화에서 실행하세요.

/mcp auth onebyone

공식 문서

Windsurf / Cascade

Cascade의 … Actions 메뉴 → MCPs → Open MCP config file을 열고 mcp_config.json에 추가한 뒤 로그인 안내를 따르세요.

{
  "mcpServers": {
    "onebyone": {
      "serverUrl": "https://mcp.one-by.one/mcp"
    }
  }
}

Windsurf 공식 문서는 현재 Devin Desktop으로 연결되며 기존 Cascade 에이전트용이에요. 새 Devin Local 탭은 설정 방식이 달라요.

공식 문서

다른 MCP 앱

같은 주소로 원격 Streamable HTTP와 OAuth를 사용하세요. 앱이 OAuth 정보 감지와 동적 클라이언트 등록을 지원해야 하고, 로컬 도구는 loopback 주소를 쓸 수 있어요. 에이전트는 이 페이지를 Markdown(영어)으로 읽을 수 있어요.

연결 해제

연결의 승인 페이지에서 Disconnect를 누르거나 AI 앱에서 설정을 삭제해도 돼요. 이후 접근은 차단되지만 one-by.one 기록이나 AI가 이미 받은 정보는 삭제되지 않아요. AI 연결에는 계정의 해당 구독 이용 권한이 필요해요.

AI 에이전트에게 전달할 지시문

에이전트에게 붙여 넣으면 서버를 추가하고 로그인을 시작해요.

AI 에이전트에게 전달할 지시문
one-by.one MCP 서버를 당신(AI 에이전트)에 추가하고 연결해 주세요.

- 서버 주소: https://mcp.one-by.one/mcp
- 방식: 원격 Streamable HTTP. 서버 이름은 "onebyone"으로 해 주세요.
- 인증: OAuth 로그인(동적 클라이언트 등록). API 키나 토큰은 필요 없으니 저에게 요구하지 마세요.

진행 순서:
1. 기존 MCP 서버 설정은 그대로 두고 이 서버만 추가해 주세요. 직접 설정을 바꿀 수 없다면, 이 클라이언트에 맞는 정확한 명령이나 설정을 알려 주세요.
2. OAuth 로그인을 시작해 주세요. 브라우저를 열 수 없으면 로그인 링크를 보여 주세요.
3. 저는 one-by.one 계정으로 로그인하고 권한(context:read, activity:read, activity:write)을 승인하겠습니다. 승인 화면에 "Unverified app"으로 표시될 수 있는데, 확인되지 않은 클라이언트에는 정상적인 표시입니다.
4. 제가 돌아오면 onebyone 도구가 보이는지 확인해 주세요. 제가 요청하기 전에는 계획을 만들거나 바꾸지 마세요. AI 연결 3개 한도 때문에 거절되면 알려 주세요.

클라이언트별 안내: https://one-by.one/connect/index.md
