one-by.one × MCP

쓰던 AI, 그대로 연결하세요.

ChatGPT, Claude, 터미널, 에디터까지. 원격 HTTP와 OAuth 로그인을 지원하는 MCP 에이전트라면 one-by.one에 연결할 수 있습니다. AI가 계획하고, iPhone에서는 한 장씩 실행하세요.

앱은 현재 영어로 제공됩니다.

프롬프트 붙여 넣기내 도구 고르기에이전트용 Markdown(영어)

AI 에이전트에게 이렇게 붙여 넣으세요

가장 빠른 방법입니다. 에이전트가 서버를 추가하고 로그인을 시작한 뒤, 여러분이 승인할 때까지 기다립니다.

AI 에이전트에게 전달할 지시문
one-by.one MCP 서버를 당신(AI 에이전트)에 추가하고 연결해 주세요.

- 서버 주소: https://mcp.one-by.one/mcp
- 방식: 원격 Streamable HTTP. 서버 이름은 "onebyone"으로 해 주세요.
- 인증: OAuth 로그인(동적 클라이언트 등록). API 키나 토큰은 필요 없으니 저에게 요구하지 마세요.

진행 순서:
1. 기존 MCP 서버 설정은 그대로 두고 이 서버만 추가해 주세요. 직접 설정을 바꿀 수 없다면, 이 클라이언트에 맞는 정확한 명령이나 설정을 알려 주세요.
2. OAuth 로그인을 시작해 주세요. 브라우저를 열 수 없으면 로그인 링크를 보여 주세요.
3. 저는 one-by.one 계정으로 로그인하고 권한(context:read, activity:read, activity:write)을 승인하겠습니다. 승인 화면에 "Unverified app"으로 표시될 수 있는데, 확인되지 않은 클라이언트에는 정상적인 표시입니다.
4. 제가 돌아오면 onebyone 도구가 보이는지 확인해 주세요. 제가 요청하기 전에는 계획을 만들거나 바꾸지 마세요. AI 연결 3개 한도 때문에 거절되면 알려 주세요.

클라이언트별 안내: https://one-by.one/connect/index.md

에이전트가 자신의 설정을 바꿀 수 없으면 어떻게 입력할지 알려 줍니다. 아래에서 사용하는 도구의 단계를 따라 해도 되고, 에이전트에게 이 페이지의 Markdown 버전(영어)을 전달해도 됩니다.

  1. 서버 추가. AI 도구에 서버 주소를 추가하세요. 연결 방식은 Streamable HTTP입니다.
  2. 로그인. 브라우저가 열리면 기존 one-by.one 계정으로 로그인하세요.
  3. 승인. 앱 이름과 요청 권한을 확인하고 승인한 뒤 AI 도구로 돌아가세요.

API 키나 별도의 개발자 등록은 필요 없습니다. 웹 커넥터와 로컬 도구 모두 클라이언트를 자동 등록할 수 있으며, 로컬 도구의 loopback 주소로 돌아오는 로그인도 지원합니다.

확인되지 않은 앱은 승인 화면에 Unverified app으로 표시됩니다. 연결하려던 도구가 맞는지 확인하고 승인하세요.

승인하는 권한

  • context:read — 계획에 필요한 공유 정보를 읽습니다.
  • activity:read — 계획과 활동 기록을 읽습니다.
  • activity:write — 계획을 만들거나 바꾸고 활동을 기록합니다.

AI에 공유되는 정보는 개인정보 처리방침(영어)에서 확인하세요.

어떤 도구를 쓰시나요?

기존 설정을 지우지 말고 onebyone 항목만 추가하세요. 아래 예제는 OAuth 정보를 자동 감지하므로 토큰이나 클라이언트 비밀 값을 입력하지 않습니다. 메뉴 이름은 버전에 따라 달라질 수 있습니다.

ChatGPT · Apps / Connectors

앱

  1. 계정에 허용된 Developer mode를 켜세요. 현재 공식 문서는 Settings → Security and login → Developer mode를 안내합니다.

  2. Plugins에서 +를 눌러 이름을 one-by.one으로 정하고 서버 주소를 입력하세요. 버전에 따라 Apps 또는 Connectors로 표시될 수 있습니다.

    ChatGPT server URL
    https://mcp.one-by.one/mcp

  3. 연결을 만들고 one-by.one 로그인과 승인을 마치세요.

  4. 새 대화의 도구 메뉴에서 선택하세요. 요금제와 워크스페이스 정책에 따라 사용 가능 여부가 달라집니다.

공식 설정 문서

Claude · claude.ai / Desktop

앱

  1. Customize → Connectors에서 커스텀 웹 커넥터를 추가하세요.

  2. 이름은 one-by.one, 주소는 아래와 같습니다.

    Claude server URL
    https://mcp.one-by.one/mcp

  3. 로그인 인증을 선택하고, 클라이언트 등록 방법이 보이면 자동 등록(Register automatically)을 선택하세요.

  4. one-by.one 로그인과 승인을 마친 뒤 대화에서 커넥터를 켜세요.

Claude Desktop에서도 같은 원격 커넥터를 사용하세요. Team·Enterprise에서는 관리자가 먼저 추가해야 할 수 있습니다.

공식 설정 문서

Claude Code

터미널

  1. 터미널에서 아래 명령을 실행하세요.

    Claude Code · terminal
    claude mcp add --transport http onebyone https://mcp.one-by.one/mcp

  2. Claude Code 대화에서 /mcp를 입력하고 onebyone을 선택한 뒤 브라우저에서 로그인하세요.

    Claude Code · in-session
    /mcp

공식 설정 문서

Codex CLI

터미널

  1. 터미널에서 서버를 추가하고 로그인하세요.

    Codex CLI · terminal
    codex mcp add onebyone --url https://mcp.one-by.one/mcp
codex mcp login onebyone

  2. 설정 파일을 선호한다면 ~/.codex/config.toml에 아래 TOML 항목을 추가한 뒤 codex mcp login onebyone을 실행하세요.

    Codex · config.toml
    [mcp_servers.onebyone]
url = "https://mcp.one-by.one/mcp"

  3. Codex에서 /mcp로 연결 상태를 볼 수 있습니다.

공식 설정 문서

Cursor

설정 파일

  1. 프로젝트의 .cursor/mcp.json에 아래 항목을 추가하세요. 모든 프로젝트에서 쓰려면 ~/.cursor/mcp.json을 사용하면 됩니다.

    Cursor · mcp.json
    {
  "mcpServers": {
    "onebyone": {
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

  2. 저장 후 Cursor를 다시 열고 OAuth 로그인 안내를 따라가세요. 연결된 도구는 Agent에서 사용할 수 있습니다.

공식 설정 문서

VS Code · GitHub Copilot

설정 파일

  1. .vscode/mcp.json에 아래 설정을 추가하세요. 사용자 공통 설정은 MCP: Open User Configuration으로 열 수 있습니다.

    VS Code · mcp.json
    {
  "servers": {
    "onebyone": {
      "type": "http",
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

  2. 편집기에 표시되는 onebyone의 Start를 누르고 브라우저에서 로그인하세요.

  3. Copilot Agent에서 도구를 켜세요.

공식 설정 문서

Gemini CLI

설정 파일

  1. ~/.gemini/settings.json 또는 프로젝트의 .gemini/settings.json에 아래 항목을 추가하세요. OAuth 정보는 자동으로 감지합니다.

    Gemini CLI · settings.json
    {
  "mcpServers": {
    "onebyone": {
      "httpUrl": "https://mcp.one-by.one/mcp"
    }
  }
}

  2. Gemini CLI 대화에서 아래 인증 명령으로 로그인하세요.

    Gemini CLI · in-session
    /mcp auth onebyone

공식 설정 문서

Windsurf / Cascade

설정 파일

  1. Cascade의 … Actions 메뉴 → MCPs → Open MCP config file로 설정 파일을 여세요.

  2. mcp_config.json에 아래 항목을 추가하세요.

    Cascade · mcp_config.json
    {
  "mcpServers": {
    "onebyone": {
      "serverUrl": "https://mcp.one-by.one/mcp"
    }
  }
}

  3. 저장한 뒤 OAuth 로그인 안내를 따라가세요.

Windsurf 공식 문서는 현재 Devin Desktop으로 연결되며 기존 Cascade 에이전트용입니다. 설치된 버전의 설정 파일 열기 기능을 이용하세요. 새 Devin Local 탭은 설정 방식이 다릅니다.

공식 설정 문서

연결은 최대 3개. 해제도 직접.

계정당 AI 연결은 최대 3개입니다. 새 연결을 추가할 자리가 없으면 iPhone 앱의 Settings › AI apps에서 기존 연결 옆의 Disconnect를 누르세요. 그 연결의 one-by.one 승인 페이지에서 Disconnect를 누르거나, AI 도구 쪽에서 설정을 삭제해도 됩니다.

연결을 해제하면 이후 접근이 차단됩니다. one-by.one 기록이나 AI가 이미 받은 정보는 삭제되지 않습니다. AI 연결에는 계정의 해당 구독 이용 권한이 필요합니다.

다른 MCP 에이전트를 쓰시나요?

같은 서버 주소로 원격 Streamable HTTP와 OAuth를 사용하세요. 도구가 OAuth 정보 감지와 동적 클라이언트 등록을 지원해야 합니다. 로컬 도구는 로그인 뒤 loopback 주소로 돌아올 수 있습니다. 설정 형식은 해당 도구의 공식 문서를 확인하세요. 에이전트는 이 페이지를 Markdown(영어)으로 읽을 수 있습니다.

연결에 문제가 있나요? 지원 페이지(영어)에서 도움을 받으세요.
