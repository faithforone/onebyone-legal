ChatGPT Calendar Integration: Google, Apple (iCloud) and Outlook

By one-by.one · Updated November 27, 2026 · 3 min read

ChatGPT calendar integration works through plugins: open Settings > Plugins and connect Google Calendar, iCloud Calendar or Outlook Calendar. Google Calendar creates, updates and deletes events, iCloud creates and changes them, and Outlook edits supported shared calendars.

ChatGPT Google Calendar integration

  1. Open Settings > Plugins and select Google Calendar.
  2. Select Install plugin if shown, then Connect.
  3. Pick the Google account and approve the permissions.
  4. In a chat, type @ and choose Google Calendar, or use +.

ChatGPT can then summarize a day, check availability, list calendars, and create, update or delete events.

ChatGPT Apple Calendar integration (iCloud)

The iCloud Calendar plugin launched October 27, 2026, on all ChatGPT plans, on web, desktop and iOS. It lists iCloud calendars, finds events and creates or changes them.

  1. With two-factor authentication on, make an app-specific password at account.apple.com.
  2. In Settings > Plugins > iCloud Calendar, select Install plugin if shown, then Connect.
  3. Enter your primary Apple Account email and that password, never your regular Apple password.

It reads Apple-hosted iCloud calendars, not every calendar shown in the iPhone Calendar app.

ChatGPT Outlook calendar integration

Outlook Calendar creates, updates, cancels or deletes events on supported shared calendars. In Settings > Plugins > Outlook Calendar, select Install plugin if shown, then Connect, and sign in with the Microsoft account that already has the calendar. If your organization requires it, an administrator grants consent first.

ChatGPT Google Calendar integration not working

  1. “All permissions are required”: select Reconnect and approve the permissions for the apps you picked.
  2. “ChatGPT needs all requested permissions”: select Try again, then Select all on Google’s screen.
  3. Start a new chat and pick the plugin with @. An app can show Connected yet be unavailable in the current chat.
  4. Disabled by admin: ask your ChatGPT workspace admin to review the plugin; if Google blocks a scope, the Google Workspace admin approves it.
  5. iCloud stopped after a password change: app-specific passwords were revoked; make a new one.

ChatGPT calendar MCP

A calendar MCP server goes in as a custom MCP server: turn on Developer mode if your account allows it (Settings > Security and login > Developer mode), then open Plugins, select + and enter the server URL. Availability depends on your plan and workspace policy.
