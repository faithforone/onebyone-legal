Connect an AI app

Connect ChatGPT, Claude, Codex, Cursor or any AI app that supports remote MCP. Your AI plans; the iPhone app shows one card at a time.

Server URL

https://mcp.one-by.one/mcp

Streamable HTTP, OAuth sign-in. No API key or token.

How it works

Add the server URL to your AI app, sign in to your one-by.one account in the browser and approve the access. You can connect up to 3 apps. To disconnect one, tap Disconnect in Settings › AI apps in the iPhone app.

Permissions

The app can:

  • context:read — read the context you share for planning.
  • activity:read — read your plans and recorded activity.
  • activity:write — create or update plans and save activity.

An app we have not verified shows as Unverified app on the approval screen; check it is the one you meant to connect. The Privacy Policy covers what your AI receives.

Set up your app

Merge only the onebyone entry into your existing settings. No tokens or client secrets are needed. Menus vary by version.

ChatGPT · Apps / Connectors

  1. Turn on Developer mode if your account allows it (Settings → Security and login → Developer mode).
  2. Open Plugins, select +, name it one-by.one and enter https://mcp.one-by.one/mcp. Older versions call this Apps or Connectors.
  3. Finish the sign-in, then pick it from the tools menu in a new chat. Availability depends on your plan and workspace policy.

Official guide

Claude · claude.ai / Desktop

  1. Open Customize → Connectors and add a custom web connector.
  2. Name it one-by.one and enter https://mcp.one-by.one/mcp.
  3. Choose sign-in authentication and automatic client registration if shown, finish the sign-in, then enable the connector in your conversation.

Claude Desktop uses the same connector. Team and Enterprise workspaces may need an owner to add it first.

Claude Code

Run in your terminal:

claude mcp add --transport http onebyone https://mcp.one-by.one/mcp

Then run /mcp in a session, select onebyone and authenticate in the browser.

Official guide

Codex CLI

Add the server and sign in:

codex mcp add onebyone --url https://mcp.one-by.one/mcp
codex mcp login onebyone

Or add this to ~/.codex/config.toml and run codex mcp login onebyone:

[mcp_servers.onebyone]
url = "https://mcp.one-by.one/mcp"

Check the connection with /mcp in Codex.

Official guide

Cursor

Add this to .cursor/mcp.json (project) or ~/.cursor/mcp.json (all projects):

{
  "mcpServers": {
    "onebyone": {
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

Restart Cursor, complete the sign-in prompt and use the tools in Agent.

Official guide

VS Code · GitHub Copilot

Add this to .vscode/mcp.json, or open user settings with MCP: Open User Configuration:

{
  "servers": {
    "onebyone": {
      "type": "http",
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

Start onebyone from the editor, sign in in the browser and enable its tools in Copilot Agent.

Official guide

Gemini CLI

Add this to ~/.gemini/settings.json or the project’s .gemini/settings.json. OAuth is discovered automatically.

{
  "mcpServers": {
    "onebyone": {
      "httpUrl": "https://mcp.one-by.one/mcp"
    }
  }
}

Then, in a Gemini CLI session:

/mcp auth onebyone

Official guide

Windsurf / Cascade

In Cascade, open the … Actions menu → MCPs → Open MCP config file. Add this to mcp_config.json and sign in when prompted:

{
  "mcpServers": {
    "onebyone": {
      "serverUrl": "https://mcp.one-by.one/mcp"
    }
  }
}

The official Windsurf guide now redirects to Devin Desktop and covers the legacy Cascade agent. Newer Devin Local tabs use a different setup.

Other MCP apps

Use the same URL with remote Streamable HTTP and OAuth. The app must support OAuth discovery and dynamic client registration; local tools can use a loopback redirect. Agents can read this page as Markdown.

Disconnecting

You can also use Disconnect on the connection’s authorization page, or remove it in the AI app. This stops future access; it does not delete your one-by.one records or what the AI already received. AI connections require your account’s applicable subscription entitlement.

Prompt for your AI agent

Paste this into your agent to add the server and start the sign-in.

Instruction for your AI agent
Add the one-by.one MCP server to yourself and connect it.

- Server URL: https://mcp.one-by.one/mcp
- Transport: remote streamable HTTP. Name the server "onebyone".
- Auth: OAuth sign-in with dynamic client registration. There is no API key or token, so do not ask me for one.

Steps:
1. Add the server to your MCP configuration and keep my existing servers. If you cannot change your own configuration, give me the exact command or setting for this client.
2. Start the OAuth sign-in. If you cannot open a browser, show me the sign-in link.
3. I will sign in to my one-by.one account and approve the permissions: context:read, activity:read and activity:write. The approval screen may label you "Unverified app"; that is normal for unverified clients.
4. When I am back, confirm that the onebyone tools are listed. Do not create or change any plans until I ask. If the connection is refused because the limit of 3 AI connections is reached, tell me.

Instructions for each client: https://one-by.one/connect/index.md
