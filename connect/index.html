Paste this into your AI agent

The fastest way to connect. Your agent adds the server, starts the sign-in and waits while you approve.

Instruction for your AI agent
Add the one-by.one MCP server to yourself and connect it.

- Server URL: https://mcp.one-by.one/mcp
- Transport: remote streamable HTTP. Name the server "onebyone".
- Auth: OAuth sign-in with dynamic client registration. There is no API key or token, so do not ask me for one.

Steps:
1. Add the server to your MCP configuration and keep my existing servers. If you cannot change your own configuration, give me the exact command or setting for this client.
2. Start the OAuth sign-in. If you cannot open a browser, show me the sign-in link.
3. I will sign in to my one-by.one account and approve the permissions: context:read, activity:read and activity:write. The approval screen may label you "Unverified app"; that is normal for unverified clients.
4. When I am back, confirm that the onebyone tools are listed. Do not create or change any plans until I ask. If the connection is refused because the limit of 3 AI connections is reached, tell me.

Instructions for each client: https://one-by.one/connect/index.md

An agent that cannot change its own settings will tell you what to enter. You can also follow the steps for your tool below, or give your agent the Markdown version of this page.

One URL. Sign in once.

Transport
Streamable HTTP (remote)
Sign-in
OAuth with dynamic client registration. No API key or token.
Permissions
context:read, activity:read, activity:write
Limit
3 AI connections per account
Local tools
Loopback redirects are allowed
  1. Add the server. Add the server URL in your AI tool using Streamable HTTP.
  2. Sign in. Follow the browser prompt and sign in to your existing one-by.one account.
  3. Approve. Review the app name and permissions, then approve access. Return to your AI tool.

No API key or separate developer registration is needed. one-by.one supports dynamic client registration for web connectors and local clients, including local loopback redirects.

An app we have not verified appears as Unverified app on the approval screen. Check that it is the tool you meant to connect.

What you approve

  • context:read — read the context you share for planning.
  • activity:read — read your plans and recorded activity.
  • activity:write — create or update plans and save activity.

ChatGPT · Apps / Connectors

App

  1. Turn on Developer mode if your account allows it. The current setup guide uses Settings → Security and login → Developer mode.

  2. Open Plugins, select +, name the connection one-by.one and enter the public server URL. Older interfaces may call this Apps or Connectors.

    ChatGPT server URL
    https://mcp.one-by.one/mcp

  3. Create the connection and finish the one-by.one OAuth sign-in.

  4. Select it from the tools menu in a new chat. Availability depends on your plan and workspace policy.

Claude · claude.ai / Desktop

App

  1. Open Customize → Connectors and add a custom web connector.

  2. Name it one-by.one and paste the server URL.

    Claude server URL
    https://mcp.one-by.one/mcp

  3. Choose sign-in authentication and automatic client registration when that option is shown.

  4. Complete the OAuth flow, then enable the connector in your conversation.

Use the same remote custom connector in Claude Desktop. Team and Enterprise workspaces may need an owner to add it first.

Codex CLI

Terminal

  1. Add the server and start OAuth login from your terminal.

    Codex CLI · terminal
    codex mcp add onebyone --url https://mcp.one-by.one/mcp
codex mcp login onebyone

  2. Prefer a config file? Merge this TOML entry into ~/.codex/config.toml and run codex mcp login onebyone.

    Codex · config.toml
    [mcp_servers.onebyone]
url = "https://mcp.one-by.one/mcp"

  3. Use /mcp in Codex to inspect the connection.

Cursor

Config file

  1. Merge this entry into .cursor/mcp.json in your project, or ~/.cursor/mcp.json for all projects.

    Cursor · mcp.json
    {
  "mcpServers": {
    "onebyone": {
      "url": "https://mcp.one-by.one/mcp"
    }
  }
}

  2. Save and restart Cursor, then complete the OAuth prompt and use the tools in Agent.

Official setup guide

Three connections. You stay in control.

You can have up to three AI connections per account. To make room, open Settings › AI apps in the iPhone app and tap Disconnect next to a connection. You can also use Disconnect on its one-by.one authorization page, or remove its configuration in the AI tool.

Disconnecting stops future tool access. It does not delete your one-by.one records or information the AI already received. AI connections require your account’s applicable subscription entitlement.

Another MCP agent?

Use the same server URL with remote Streamable HTTP and OAuth. Your client must support OAuth discovery and dynamic registration. Local tools can return to a loopback redirect after sign-in. Check your tool’s official documentation for its configuration format. Agents can read this page as Markdown.
